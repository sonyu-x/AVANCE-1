CONCEPTOS BÁSICOS

¿Por qué es importante la ciberseguridad?

La ciberseguridad permite proteger dispositivos, cuentas, redes y datos frente a diferentes amenazas digitales.

🔐

Protege tus contraseñas

AMENAZAS DIGITALES

Principales amenazas de Internet

Conocer las amenazas permite tomar mejores decisiones al utilizar Internet.

Tabla de amenazas y medidas de prevención
Amenaza Descripción Riesgo Prevención
Phishing Mensajes o sitios falsos utilizados para obtener información. Alto Verificar enlaces y remitentes.
Malware Software diseñado para afectar un dispositivo o acceder a información. Alto Mantener actualizado el sistema.
Contraseñas débiles Claves fáciles de descubrir o reutilizadas. Medio Utilizar contraseñas fuertes y únicas.
Redes Wi-Fi inseguras Redes públicas o poco protegidas. Medio Evitar operaciones sensibles.
La prevención es una de las principales medidas para reducir los riesgos digitales.
